# Tiny ImageNet Custom CNN

This repository contains a custom Convolutional Neural Network (CNN) designed and trained from scratch on the Tiny ImageNet dataset.

## Objectives
- Build a CNN from scratch without using pretrained models
- Understand and apply modern CNN design principles
- Create a scalable and extensible codebase for future computer vision projects

## Dataset
Tiny ImageNet (200 classes, 64×64 RGB images)

## Future Work
- Performance optimization
- OpenCV-based preprocessing
- Comparison with transfer learning models
